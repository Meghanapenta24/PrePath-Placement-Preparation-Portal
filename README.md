# PrePath – Placement Preparation Portal

PrePath is a web-based placement preparation portal designed to help students prepare for campus placements and improve their job-readiness skills.

## 🎯 Project Objective

The main objective of PrePath is to provide students with a platform where they can prepare for placement activities, access learning resources, and improve their technical and interview skills.

## ✨ Key Features

- **User Authentication:** Registration and login functionality.
- **Dashboard:** A home page to access placement preparation activities.
- **Aptitude Preparation:** Practice resources for aptitude topics.
- **Coding Preparation:** Resources to improve programming skills.
- **Technical Interview Preparation:** Support for preparing technical interview topics.
- **HR Interview Preparation:** Guidance for HR interview preparation.
- **Progress Tracking:** A planned feature to monitor preparation progress.

## 🛠️ Technologies Used

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, Flask
- **Database:** SQLite
- **Version Control:** Git and GitHub

## 💻 How to Run the Project Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Meghanapenta24/PrePath-Placement-Preparation-Portal.git
   ```

2. Navigate to the project folder:

   ```bash
   cd PrePath-Placement-Preparation-Portal
   ```

3. Install Flask:

   ```bash
   pip install flask
   ```

4. Run the application:

   ```bash
   python app.py
   ```

5. Open your browser and visit:

   `http://127.0.0.1:5000`
